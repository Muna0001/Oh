I make the tools I want for my own music.

I'm Nate Mueller. I'm a designer and developer, and a music lover first. I kept needing tools that didn't exist the way I wanted them: a chord instrument that doesn't ask you to know theory first, a polysynth that lives in a browser tab, a sample organizer that doesn't take my library hostage. So I built them. I use them on my own records before anyone else hears about them.

They're all built solo. If something about them feels opinionated, that's why.

Oacoma

I record synth pop as Oacoma, from Minneapolis. It's where every Oh! tool gets tested. The synth lines and the sample flips both start there.
